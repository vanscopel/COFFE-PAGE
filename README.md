☕ Página de Café - Landing Page
Este projeto é uma página simples desenvolvida para uma cafeteria fictícia, com o objetivo de praticar desenvolvimento front-end utilizando HTML e CSS.

🚀 Tecnologias utilizadas:
HTML5
CSS3

🎯 Funcionalidades:
Layout de página inicial para negócio 
Seções informativas (apresentação, produtos ou serviços)
Estilização personalizada com CSS

🌐 Demonstração:
O projeto está hospedado e pode ser acessado pelo link abaixo:
👉 https://vanscopel.github.io/COFFE-PAGE/

📌 Objetivo do projeto:
Praticar estruturação de páginas web e estilização com CSS, simulando um site institucional simples.
